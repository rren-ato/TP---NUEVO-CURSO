# 📚 TP — Nuevo Curso

Repositorio destinado a conservar y organizar el **material de las clases del profesor Huiza** correspondiente al nuevo curso.

El objetivo principal es mantener un respaldo organizado de las clases, materiales y recursos utilizados durante el ciclo, facilitando su consulta y preservación.

> [!NOTE]
> Este repositorio funciona principalmente como **backup y archivo académico**. El contenido puede actualizarse conforme avance el curso.

---

## 🎯 Objetivo

Este repositorio busca:

- 📚 Conservar el material utilizado durante las clases.
- 💾 Mantener un respaldo independiente del material académico.
- 🗂️ Organizar el contenido por ciclo y periodo.
- 🔗 Centralizar enlaces a recursos externos.
- 📖 Facilitar la consulta del material posteriormente.
